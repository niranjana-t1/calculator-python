# Python Calculator

A simple command-line calculator built with Python.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Power (**)
* Division-by-zero handling
* Input validation
* Exit option

## Concepts Used

* Functions
* Loops (while)
* Conditional Statements (if, elif)
* User Input
* Return Values
* Error Handling

## How to Run

1. Download the Python file.
2. Open a terminal in the project folder.
3. Run:
        python calculator.py
